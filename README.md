# Aparcar

Aplicación Windows para la gestión de estacionamientos, lavadero y abonados.

**Estado:** desarrollo inicial; no apta para cobros reales ni uso comercial.

El desarrollo comienza en ramas de trabajo. La versión inicial utiliza WinUI 3, C# y SQLite, con arquitectura preparada para futuras cajas conectadas.

Consultá los cambios propuestos en los pull requests antes de integrarlos.
